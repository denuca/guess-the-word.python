About Q-Words

What is Q-Words?

Q-Words is a fully accessible word-guessing game where players attempt to discover a hidden word within a limited number of attempts. Similar to popular word games, Q-Words challenges your vocabulary and deductive reasoning skills while providing an excellent experience for all users, including those using assistive technologies.

How to Play

  1. Choose your difficulty: Easy (4 letters), Medium (6 letters), or Hard (8 letters)
  2. Make your guess: Enter a word of the correct length
  3. Read the feedback:
    • + Correct letter in correct position
    • ? Correct letter in wrong position
    • x Letter not in the word
  4. Keep guessing: Use the feedback to make better guesses
  5. Win or lose: Find the word before running out of attempts!

💡 Accessibility Tips

  • Screen Readers: All game feedback is announced, including guess results and game status
  • Focus Indicators: Clear blue outlines show which element has keyboard focus
  • Skip Links: Press Tab on any page to access "Skip to main content" link
  • Live Updates: Game status and feedback are automatically announced to screen readers
  • Error Messages: Input validation errors are clearly announced and explained

Technical Details

Q-Words was originally built in Java Spring Boot and has been successfully migrated to Python Flask, maintaining 100% functional equivalence while improving performance, maintainability, and accessibility.

  • Keyboard-only navigation support
